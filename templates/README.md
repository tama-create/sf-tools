# force-xxxx

## 1. 概要

Salesforce プロジェクト（管理者が sf-tools の `sf-init.sh` で作成）。

## 2. 作業の始め方

- 開発者は、作業フォルダ（例: `~/sf`）で `sf-job.sh` を実行して作業を始め、自動で開くランチャー（`sf-launcher.sh`）の番号で進める。
- 共有の環境（`main` / `staging` / `develop`）への反映は、PR をマージすると、GitHub Actions が行う。手元から反映できるのは、自分用の組織だけ。
- 使い方: https://tama-create.github.io/sf-tools/
