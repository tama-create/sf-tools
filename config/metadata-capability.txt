# ==============================================================================
# config/metadata-capability.txt - メタデータの種類ごとの「リリース・削除」の可否
# ==============================================================================
# bin/sf-typecheck.sh（lib/typecheck.js）が、実際の組織で、種類ごとに、リリース → 削除を試して作った表。
# bin/sf-check.sh が、この表を読み、ターゲットファイルに書いた時点で、「ng」はエラー・「limited」は警告にする。
#
# 列（タブ区切り）: 種類 / release / delete / 備考
#   ok      : 実際の組織で、確認できた
#   ng      : 確認済みで、必ずできない（sf-check.sh が、エラーにする）
#   limited : 条件（権限・使用中・標準のもの・移行済み など）によって、できないことがある（sf-check.sh が、警告にする）
#   unknown : 確認していない・判定できない（標準の部品しかない・サンプルを作れない など。何もしない）
#
# 確認した環境: Developer Edition（API 64.0）。組織・権限・機能で、結果が変わることがある。
# 更新: sf-typecheck.sh --org <個人用のエイリアス> の結果を、確認して、反映する（--out で、別のファイルに出せる）。
# ==============================================================================
