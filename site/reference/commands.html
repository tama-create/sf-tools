📋 コマンド一覧

sf-tools のコマンドの一覧です。コマンドは、すべて ~/sf-tools/bin/ にあります。どのコマンドも、--help（または -h）を付けると、概要・オプション・処理の流れを表示します。

一覧

「sfl のメニュー」の ○ は、sfl のメニューから選べるコマンドです（ランチャー）。🔑 は管理者専用、⚠️ は使うときに注意が必要なコマンドです（次の節）。

管理者専用コマンドの安全ガード

🔑 のついたコマンドは管理者専用です。実行すると、赤い警告ボックスが表示されて、続けてよいかを聞かれます（Y / N / q）。まちがえて実行したときは、N か q で、止められます。

  • GITHUB_ACTIONS=true が設定されている環境（GitHub Actions 上）では、確認をスキップして自動で実行します。
  • gh を使うコマンドは、起動したときに、gh でログインしているユーザーが、リポジトリのオーナーと同じかを確かめます。違っていれば、そこで止まります。
    ただし、オーナーが GitHub 組織（例: tamashimon-org）で、認証ユーザーがその組織の有効な管理者（admin）なら、そのまま続行します。組織の一般メンバーや、組織の情報を取得できない場合は中断します（gh auth switch で正しいアカウントに切り替えてから、もう一度実行してください）。
