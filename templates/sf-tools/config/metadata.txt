# ==============================================================================
# sf-tools/config/metadata.txt
# ==============================================================================
# sf-metasync.sh が Salesforce 組織から定期取得するメタデータタイプの一覧。
#
# 【記述ルール】
#   - 1行につき1つのメタデータタイプ名を記載する（行の途中に、コメントは書けない）
#   - "#" で始まる行はコメントとして無視される
#   - 空行は無視される
#
# 【この一覧の前提】
#   この標準セットは、Developer Edition（Sales・Service の標準機能つき）でのみ、リリースと削除を確認しています。
#   ほかのエディション・製品（Service Cloud・Experience Cloud・業種クラウドなど）で使う場合は、
#   下の「機能が必要なもの」のコメントを外すか、必要な種類を、この一覧に足してください（設定ファイルだけで調整できます）。
#   足した種類が、その組織で、リリース・削除できるかは、組織の機能・権限で決まります。
#   確認は bin/sf-typecheck.sh で行えます（確認の状況は sf-typecheck.sh --coverage）。
#   取得対象に、その組織に無い種類があっても、警告になるだけで、取得は続きます。
#
# 【区分】
#   1. 標準セット           : 有効。Developer Edition で、リリース・削除を確認済み
#   2. 標準だが制限あり     : 有効。更新のみ・権限による・未確認の部分がある（理由は、各行の上のコメント）
#   3. 機能が必要なもの     : コメントアウト。Service Cloud・Experience Cloud など。使う組織だけ、外す
#   4. 未確認               : コメントアウト。確認できていない。使う場合は、外して、リリースを確かめる
#   5. 参考                 : コメントアウト。そのほかの種類の候補（業種クラウド・AI・分析など）
#
# 【参考】利用可能なメタデータタイプ一覧:
#   https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_types_list.htm
#   変更セットで扱える種類の一覧: config/changeset-types.txt（sf-tools 側）
# ==============================================================================

CustomObjectTranslation

ConnectedApp
