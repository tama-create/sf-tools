sf-tools

Salesforce 開発の「毎日の手間」を、コマンド一本にするツールキットです。

環境構築、デプロイ、事前チェック、メタデータの同期。Salesforce の開発で毎回発生する作業を、シェルスクリプトでまとめて自動化します。 ~/sf-tools に置き、各 Salesforce プロジェクト（force-* フォルダ）から呼び出して使います。 変更の検証とリリースは、GitHub Actions が自動で行います。

最短で試す

前提のツール（Git・Salesforce CLI・GitHub CLI など）が入っている場合の流れです。詳しくは 前提条件とインストール を見てください。

  1. sf-tools を配置します。

    git clone https://github.com/tama-create/sf-tools.git ~/sf-tools

  2. プロジェクトの作業フォルダで、新しい作業を始めます。ブランチ名を入力するだけで、作業用のクローンの準備から VS Code の起動までが進みます。

    ~/sf-tools/bin/sf-job.sh

  3. 作業が済んだら、変更をまとめてコミットして送ります。

    sf-push.sh
Windows と Mac で動きます

Windows は Git Bash、Mac は標準のターミナルのまま使えます。確認した環境の一覧は 動作環境 にあります。
